用 Flutter 写的 PC 端音乐播放器，支持**酷狗音乐**、**网易云音乐**、**Navidrome** 与**本地音乐**四个来源。

本次更新集中在**推荐页 / 搜索页的空白占位**和**登录页的交互**上。

## 本次更新

### 页面

- **没有数据的模块不再占地方。** 推荐页的歌单、专辑、歌手、歌曲，以及搜索页的专辑、歌手、歌曲，原先即使一条数据都没有，也会照常渲染标题和内边距，页面上留下一片空白。现在这些模块各自判断自己的数据，为空就整块不出现。
- **搜索无结果时有提示。** 搜过之后一个模块都没命中时，页面原本是纯空白，看不出是「搜完了没结果」还是界面坏了，现在会在页面正中显示「无搜索结果」。

### 登录

- **「刷新二维码」按钮可用了。** 之前它是个摆设。现在点击会重新取一张二维码，并重启本轮的扫码轮询——上一轮挂在旧二维码上的轮询循环会先退出，不会和新一轮抢同一个 key。取码期间二维码位置转圈、按钮显示「刷新中...」，失败后恢复可点。
- **手机号 / 二维码切换按钮加了选中高亮。** 浅蓝底 + 蓝边，图标跟着变蓝，切换有 180ms 过渡。顺带修了一个点击问题：原先只有图标本身那一小片区域可点，圆形按钮四角的空白点不动，现在整个按钮都能点。

## 下载哪个

| 文件 | 大小 | 说明 |
| --- | --- | --- |
| `chocolate_music-1.0.2-setup.exe` | 20.1 MB | **推荐**。安装包，自动创建开始菜单和桌面快捷方式，卸载时保留你下载的音乐 |
| `chocolate_music-portable.exe` | 24.5 MB | 单文件绿色版。双击即用，首次运行会在同级目录释放程序本体 |
| `chocolate_music-1.0.2-windows-x64.zip` | 24.4 MB | 便携压缩包。解压到任意可写目录，双击 `chocolate_music.exe` |

三个包都是 Windows x64。安装包默认装到 `%LOCALAPPDATA%\Programs\ChocolateMusic`（每用户安装，不弹 UAC）。

> 下载目录默认是「可执行文件同级的 `Music` 文件夹」。所以请**不要**把绿色版放到只读位置，装到 `Program Files` 也会因为没写权限而建不出目录。想换目录可以在设置里改。

## 功能

- **账号**：二维码扫码登录、短信验证码登录，支持多账号并存与切换
- **浏览**：每日推荐、推荐歌手 / 歌单、搜索（歌曲 / 专辑 / 歌手）、歌单页、歌手页、专辑页
- **播放**：播放队列、上一首 / 下一首 / 随机 / 循环、歌词页与歌词滚动高亮、封面过渡动画
- **歌单**：新建 / 删除歌单、收藏歌曲、加入歌单、从歌单移除、歌单内搜索
- **下载**：在线歌曲下载到本地，独立下载页管理任务
- **本地音乐**：扫描本地目录，读取音频元数据（封面 / 标题 / 歌手 / 时长）并入库
- **设置**：在线播放音质（标准 / 高品 / 无损）、下载音质、下载目录

## 四个音乐源

| 来源 | 说明 |
| --- | --- |
| 酷狗音乐 | 登录、歌单、搜索、推荐、播放地址、歌词、VIP 领取 |
| 网易云音乐 | 登录、歌单、搜索、歌手 / 专辑、播放地址、歌词、广告免费听 |
| Navidrome | 自建音乐服务器，走 Subsonic API |
| 本地音乐 | 扫描本地文件，SQLite 建库 |

酷狗和网易云的接口原先依赖两台自建 Node.js 服务器，现在客户端实际用到的路由已经搬进本地 Rust crate，**直连上游**，参数组装、签名与加解密都在进程内完成，不再需要中间服务器。

## 环境要求

Windows 10 / 11 x64。播放内核（media_kit / libmpv）已随包附带，无需另外安装。
